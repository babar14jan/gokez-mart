# Gokez Mart 🛒

Hyperlocal grocery delivery platform for Kolkata.

## Structure

```
gokez_mart/
├── mart-backend/     # Node.js + Express API (Render)
├── web-mart/         # Customer web app (Cloudflare Pages)
└── web-mart-admin/   # Admin portal (Cloudflare Pages)
```

## Services

| Service | URL |
|---------|-----|
| API | https://mart-api-qzml.onrender.com |
| Customer App | https://mart.gokez.com |
| Admin Portal | https://admin.mart.gokez.com |
